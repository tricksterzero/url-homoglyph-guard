# URL Homoglyph Guard

[日本語](README.ja.md)

A Firefox extension (Manifest V3) that warns you **before a page loads** when its domain uses look-alike characters. The UI is available in English and Japanese.

For example, `аmazon.com` starts with the Cyrillic letter `а` (U+0430). Its real name is `xn--mazon-3ve.com`, a different site from `amazon.com`.

## How it works

- A blocking `webRequest.onBeforeRequest` listener (`types: ["main_frame"]`) sees every top-level page request before it is sent. Firefox passes hostnames in Punycode form (`xn--...`), so only hostnames containing `xn--` are decoded and analyzed.
- If the domain is deceptive, the request is redirected to a bundled warning page that explains which character is different and what it looks like. The main action is "Go back (recommended)"; "Accept the risk and open" is under "Details". An exception lasts until the browser is closed (`storage.session`).
- Requests redirected by HTTP (for example 302) are caught as well. While the warning is shown, the target server is not contacted.
- No data is collected or sent anywhere (`data_collection_permissions: none`).
- Firefox does not run extensions in private windows by default; the settings page explains how to allow it.

### Detection rules

Based on [UTS #39 Unicode Security Mechanisms](https://www.unicode.org/reports/tr39/) v18.0.0 (copy: `docs/sources/tr39.html`), applied to each label of the domain:

| Rule | Meaning | Examples |
|---|---|---|
| Looks like ASCII | The label contains non-ASCII characters but its skeleton is all ASCII | `аmazon`, `аррӏе` (all Cyrillic), `gοοgle` (Greek omicrons) |
| Looks like ASCII without marks | The skeleton is all ASCII once combining marks (accents etc.) are removed. An extra rule outside UTS #39; can be turned off in the settings | `аррӏе` + U+0301, `amazọn`, `münchen` |
| Mixed scripts | The restriction level is looser than Highly Restrictive | `pаypal-ログイン` (Latin + Cyrillic + Katakana) |
| Undecodable | An `xn--` label is not valid Punycode | |

Known false positives: legitimate Cyrillic domains whose letters all look like ASCII (`сбер.рф` → `c6ep`) and accented Latin domains (`münchen.de`, unless the setting is turned off). You can still open them from the warning page.

### Protecting the warning page

The warning page has to be listed in `web_accessible_resources` so that requests can be redirected to it, which also means any website can link to or embed it. To prevent a fake warning page from being used to add exceptions:

- Each redirect issues a one-time token bound to the tab and URL (valid for 1 hour). "Accept the risk and open" is shown only with a valid token, and the exception and destination come from the background script's record, not from the page URL.
- The background script only accepts messages from its own warning page in the top-level frame of a tab.
- When embedded in another page, the warning page hides its buttons. The CSP also sets `frame-ancestors 'none'`.
- If anything fails inside the blocking listener, Firefox would continue the request, so failures redirect to a warning page without a token (the site cannot be opened from there).

## Development

Requirements: Firefox, Node.js (unit tests), Python 3 (standard library only), [web-ext](https://github.com/mozilla/web-ext).

```sh
python tools/fetch_unicode_data.py   # download the Unicode data files (data/unicode/, docs/sources/)
python tools/build_data.py           # generate extension/data/*.js from data/unicode/
node --test tests/detector.test.js tests/background.test.js tests/i18n.test.js
python tests/e2e/run_e2e.py          # runs Firefox with a temporary profile via web-ext
web-ext lint --source-dir extension
```

Strings live in `extension/_locales/en/messages.json` (default) and `extension/_locales/ja/messages.json`.

### Build instructions for reviewers

- `extension/data/confusables.js`, `names.js` and `scripts.js` are generated by `tools/build_data.py` (Python 3, standard library only) from the bundled Unicode 18.0.0 files in `data/unicode/`. Do not re-download them; `tools/fetch_unicode_data.py` is only used to update the data.
- After running `python tools/build_data.py`, the `extension/` directory is the package as submitted (the same as `web-ext build --source-dir extension`). No minifier, bundler or transpiler is used.

### Signing

`tools/save_amo_credentials.py` stores the AMO API credentials outside the repository (`~/.amo/credentials.json`, readable only by the current user), and `tools/sign.py [--channel unlisted|listed]` signs a clean checkout of `HEAD` and verifies the signed `.xpi` against it. See [README.ja.md](README.ja.md) for details.
